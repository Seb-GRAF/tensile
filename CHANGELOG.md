# Changelog

## 1.0.0

First stable release of Tensile, a React 19 component library with shared motion, form behavior, and theme tokens.

- Components for actions, inputs, navigation, feedback, data display, layout, overlays, and media.
- Controlled and uncontrolled inputs, native form values, keyboard navigation, and reduced-motion support.
- Light and dark themes, prefixed styles, an optional reset, and a Tailwind 4 token bridge.
- Named icons, syntax-highlighted code blocks, date and time controls, tables, charts, and notifications.
- TypeScript declarations and an ESM package with Motion included as a runtime dependency.
- Documentation and shared demos for every component, with pre-rendered pages and framework guides.
- Package checks with Vite and Next.js consumers, server rendering, hydration, and browser interaction scenarios.
